# Included media

Every standalone project PNG, ICO and SVG image and product executable icon uses the newly generated transparent gold interwoven geometric emblem requested for DK Online. Multi-resolution icons contain 16, 24, 32, 48, 64, 128 and 256 pixel frames. Earlier illustrations, crests, copied game icons and the bundled music recording are excluded. No font file is bundled. Node.js and Three.js retain upstream licenses and notices.

Original game packs, unpacked asset caches, game executables, GameGuard, saved accounts, login tokens and personal local configuration are not included. Native/server and renderer implementation provenance has not been established by a media/secret scan; no clean-room, legal clearance or complete ownership claim is made. Runtime artwork may come from the player's separately supplied original files; those files remain outside this distributable.
